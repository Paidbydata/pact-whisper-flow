## Task Observer (skill-improvement logging)

For every substantive task (tools, decisions or deliverables), run the task-observer skill alongside the work: notice user corrections, repeated workflows, missing rules and skill gaps, and log them.

- **Skill instructions:** `Paidbydata/ai-operating-center` → `os/skills/task-observer/SKILL.md` (load its `references/` files when it says to). If your platform has the skill installed natively, use that copy.
- **Log:** private repo `Paidbydata/skill-observations`, folder `skill-observations/`, branch `main` — never this repo or your session workspace. Follow the write protocol in that repo's README exactly.
- **Identify yourself:** every observation file you create must set `source_agent` (e.g. `codex`, `chatgpt`, `gemini-cli`) — see the README.
- If either repo isn't reachable, say so and hand the observations to Roy at session end instead of logging them anywhere else.
