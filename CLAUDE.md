Invoke the task-observer skill at the start of every substantive task (tools, decisions or deliverables). Its workspace is the private repo `Paidbydata/skill-observations` (folder `skill-observations/`, branch `main`) — never this repo or the session workspace. Full rule: the global OS, `ai-operating-center/os/CLAUDE.md` → Active Skills → task-observer.

If the global OS isn't loaded (e.g. Claude Code on the web): follow the write protocol in the `skill-observations` README. If that repo isn't reachable, say so and hand the observations to Roy at session end.
